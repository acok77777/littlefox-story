# 리틀팍스 동화 레벨 1단계  — 파스텔 모바일 웹

## 수정된 부분
1편 화면을 열 때 `data/w-01.txt` 파일을 자동으로 읽도록 `script.js`를 수정했습니다.

## 파일 배치
- `index.html`
- `style.css`
- `script.js`
- `data/w-01.txt`  ← 사용자의 `w 01.txt`를 이 이름으로 바꿔 넣기
- `audio/s-01.mp3` ← 실제 음성 파일을 이 이름으로 넣기

## 텍스트 파일 읽기 형식
다음과 같이 영어 문장 다음 줄에 한국어 해석이 오도록 되어 있어야 합니다.

1번

제목: I See 나는 봐요

I see a rock.
나는 바위를 봐요.

I see an ant.
나는 개미를 봐요.

## GitHub 업로드
저장소 최상위에서 `index.html`, `style.css`, `script.js`를 교체하고 `data/w-01.txt`와 `audio/s-01.mp3`를 업로드하세요. `Settings → Pages`에서 `main` 브랜치와 `/(root)`를 선택합니다.

참고: 현재 1편만 자동 파일 로딩이 설정되어 있습니다. 완료 기록은 현재 브라우저에 저장되며 기기 간 자동 동기화되지 않습니다.
